## 📝 Cómo Usar en App Store Connect

### 1. Durante la creación de la app:
1. Ve a [App Store Connect](https://appstoreconnect.apple.com)
2. Selecciona tu app "AutoCare Pro"
3. Ve a **Información de la App**
4. En **General Information**:
   - **Privacy Policy URL:** Pega la URL de privacidad
   - **Support URL:** Pega la URL de soporte
   - **Marketing URL:** (Opcional) Pega la URL principal

### 2. En la sección de Suscripciones:
1. Ve a **Monetización** → **Suscripciones**
2. Selecciona tu grupo de suscripciones
3. En **Información de App Store**:
   - **Privacy Policy URL:** Pega la URL de privacidad
   - **Terms of Use URL:** Pega la URL de términos

3. Haz commit y push de nuevo

```bash

# Edita los archivos
git add documentos-legales-autocare-pro/

git push origin main
```

### 2. Verifica HTTPS

Asegúrate de que todas las URLs usen `https://` (no `http://`). GitHub Pages proporciona HTTPS automáticamente.
